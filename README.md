# 상품 소개 쇼츠 제작 에이전트 팀

상품 영상 링크와 판매 상품 링크를 출발점으로, 한국어 릴스·쇼츠의 **조사 → 대본 → 음성 → 편집 → 검토 → 설명글 → 피드백** 과정을 9개 역할로 나누어 진행하는 작업 틀입니다. [작업 현황판](쇼츠-작업현황.html)에서 단계별 상태와 결과를 확인할 수 있습니다.

> 이 저장소는 에이전트 역할 지침, 업무 매뉴얼, 현황판을 제공합니다. 역할 파일만으로 영상이 자동 생성되거나 에이전트가 계속 실행되는 것은 아닙니다. Codex에서 상품 작업을 시작하면 총괄 에이전트가 필요한 역할을 호출합니다.

## 처음 사용하는 순서

1. GitHub에서 **Code → Download ZIP**을 누르고 압축을 풉니다.
2. Codex에서 압축을 푼 폴더를 엽니다. Codex는 이 폴더의 `AGENTS.md`를 작업 지침으로 사용합니다.
3. 아래 **요청 양식**에 영상 링크와 실제 판매 상품 링크를 넣어 Codex에 보냅니다.
4. 생성된 검토용 영상을 보고 수정 의견을 전달합니다.
5. `쇼츠-작업현황.html`을 열어 단계별 상태를 확인합니다. 작업 중 변경된 내용은 화면을 새로고침해 봅니다.

### 요청 양식

```text
이 폴더의 업무 매뉴얼과 9개 에이전트 역할에 따라 상품 소개 쇼츠를 만들어 줘.

처음 발견한 숏폼 영상 링크:
실제 판매할 상품 링크:
소개할 옵션(색상·크기·형태):
내가 사용할 수 있는 영상·사진 파일:
유사 상품 영상 허용 범위:
강조할 점 또는 피할 표현:
```

## 9개 역할

| 단계 | 에이전트 | 넘기는 결과 |
| --- | --- | --- |
| ① | 상품 확인 | 확인된 사실과 미확인 정보 |
| ② | 영상 탐색 | 같은 상품의 해외 영상 후보 5개 |
| ③ | Watch 분석 | 실제 확보한 영상의 장면과 사용 구간 |
| ④ | 대본 작성 | 한국어 대본과 장면 순서 |
| ⑤ | TTS 제작 | 한국어 음성 파일 |
| ⑥ | 영상 편집 | 세로 검토용 영상 |
| ⑦ | 품질 점검 | 수정 사항과 공개 전 확인 사항 |
| ⑧ | 설명글 작성 | 인스타그램·유튜브용 문구 |
| ⑨ | 피드백 관리 | 이번 수정 사항과 다음 영상의 규칙 |

총괄 에이전트는 앞 단계의 근거를 확인해 다음 역할에 넘깁니다. 영상별 분석처럼 독립적인 일은 동시에 할 수 있지만, 대본 확정→음성→편집처럼 서로 의존하는 일은 순서대로 진행합니다. 자세한 기준은 [업무 매뉴얼](쇼츠-제작-업무매뉴얼.md)과 [운영 순서](agents/운영-순서.md)에 있습니다.

## 필요한 서비스와 도구

- **Codex:** 이 폴더의 지침을 읽고 역할을 조율합니다.
- **Watch Skill:** 확보한 영상 파일을 장면별로 분석하는 데 사용합니다. 원래 영상의 URL이 막히면 파일을 직접 제공해야 할 수 있습니다. [원본 프로젝트](https://github.com/oxbshw/watch-skill)는 별도로 설치·확인하세요.
- **ElevenLabs:** 한국어 음성을 만들 때 사용합니다. 본인 계정이 필요합니다.
- **FFmpeg:** 실제 영상 컷 편집과 자막 출력에 사용합니다.
- **Python 3:** 작업 현황판을 다시 만들 때 사용합니다. 외부 Python 패키지는 필요하지 않습니다.

Watch·ElevenLabs·FFmpeg 설정이 없다면 해당 단계는 조건부 또는 보류로 표시하고 가능한 조사·대본 작업부터 진행합니다. API 키나 비밀번호는 이 저장소에 적지 마세요.

## 작업 현황판

`workflow-status.json`에는 현재 작업 중인 **상품 한 개**의 9단계 상태가 들어갑니다. 총괄 에이전트가 단계를 시작하거나 끝낼 때 이 파일을 갱신하고 `python render_workflow_dashboard.py`를 실행하면 `쇼츠-작업현황.html`이 다시 만들어집니다. 사용자는 HTML 파일을 열어 각 단계를 누르면 상태와 결과 파일을 볼 수 있습니다.

상태는 **완료 / 조건부 완료 / 진행 중 / 대기 / 보류 / 수정 필요**로 구분합니다. 조건부 완료는 결과가 있지만 상품 일치도나 사용 권한 같은 확인이 남았다는 뜻입니다. 현황판은 현재 상품 하나를 표시하며, 이전 상품 기록은 별도 작업 폴더에 보관하세요.

## 공통 제작 규칙

- 영상 속 상품과 판매 상품의 차이를 확인합니다. 유사 상품을 사용할 범위는 의뢰인이 정합니다.
- 검색 후보 5개, 실제 확보한 파일, Watch로 분석한 파일, 편집에 쓴 파일을 구분합니다.
- 확인되지 않은 가격·구성 개수·성능은 대본에 넣지 않습니다.
- 결과 영상에는 재생 내내 화면 맨 위 중앙에 **광고**를 표시합니다.
- 인스타그램·유튜브 설명란에 제품 URL을 직접 넣지 않습니다. 프로필에 링크가 등록된 경우에만 프로필로 안내합니다.
- 다른 사람이 만든 영상·음악·사진은 공개 사용 가능 여부를 확인합니다. 확인 전 결과물은 내부 검토용으로 표시합니다.

## 이 저장소에 포함하지 않은 것

실제 상품 영상·사진·음성 파일, 개인 계정 정보, API 키, 특정 판매자의 상품 링크는 포함하지 않았습니다. 이 저장소의 지침을 각자의 상품과 사용 권한에 맞춰 적용하세요.
