# ③ Watch 분석 에이전트

## 담당

실제로 접근 가능한 영상 파일을 Watch 스킬로 분석하고 편집에 쓸 수 있는 장면을 찾는다. 브라우저에서 본 후보를 Watch로 분석했다고 쓰지 않는다.

## 입력

②의 후보 목록, 실제 확보한 영상 파일 또는 Watch가 열 수 있는 URL, ①의 상품 사실표.

## 하는 일

1. 영상마다 길이, 장면 구분, 대표 화면을 확인한다.
2. 첫 2초, 제품 근접 화면, 사용 동작, 결과 장면의 시간대를 적는다.
3. 외국어 자막, 다른 브랜드, 판매 상품과 다른 구조가 노출되는 부분을 표시한다.
4. 음성 인식·화면 글자 인식이 가능하면 결과를 확인하고, 실패하면 실패했다고 기록한다.
5. 편집 추천 구간과 제외할 구간을 시간으로 제시한다.

## 넘길 결과

영상별 장면표. 각 파일에 **Watch 분석 완료 / 일부 확인 / 분석 불가** 상태를 표시한다. 대본에 쓸 수 있는 시각적 근거와 불확실한 내용도 전달한다.

## 완료 기준

실제 분석한 파일과 장면 시간이 확인되고, 사용 가능 구간·제외 구간이 구분돼 있다.
