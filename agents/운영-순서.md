# 9개 에이전트 운영 순서

이 문서는 `쇼츠-제작-업무매뉴얼.md`의 4장 ①~⑨를 각각 담당할 작업 역할로 나눈 것이다. **역할 파일은 반복 사용 지침**이며, 실제 작업 때 총괄 에이전트가 해당 역할을 맡은 하위 에이전트를 호출한다. 9개가 항상 동시에 켜져 있는 것은 아니다.

| 순서 | 역할 | 받는 자료 | 다음 단계에 넘기는 결과 |
| --- | --- | --- | --- |
| ① | 상품 확인 | 최초 영상·판매 링크·옵션 | 확인된 상품 사실, 차이, 미확인 사항 |
| ② | 영상 탐색 | ①의 상품 기준 | 후보 5개와 각 후보의 일치도·언어·장면 |
| ③ | Watch 분석 | 확보한 영상 파일·후보 목록 | 장면별 분석과 사용 가능 구간 |
| ④ | 대본 작성 | ①과 ③의 결과 | 한국어 대본과 화면별 구성 |
| ⑤ | TTS 제작 | 확정 대본 | 한국어 음성 파일과 발음 점검 기록 |
| ⑥ | 영상 편집 | 화면 구성·음성·사용 가능 영상 | 세로 검토용 영상과 사용 컷 목록 |
| ⑦ | 품질 점검 | 검토용 영상·상품 사실표 | 수정 요청 또는 검토 통과 기록 |
| ⑧ | 설명글 작성 | 최종 영상·확인된 상품 정보 | 인스타그램·유튜브 설명글 |
| ⑨ | 피드백 관리 | 사용자 의견·수정본 | 이번 수정 내역과 다음 영상 규칙 |

## 총괄 에이전트가 지킬 순서

1. 사용자에게서 최초 영상 링크, 판매 링크, 정확한 옵션을 받는다. 이미 받은 정보는 다시 묻지 않는다.
2. ①을 마친 뒤 ②를 시작한다. ②의 후보 중 실제 파일을 확보한 것만 ③에 보낸다.
3. ①과 ③의 근거가 모이면 ④를 진행한다. ⑤와 ⑥은 확정 대본을 기준으로 이어서 진행한다.
4. ⑦의 지적이 있으면 관련 역할로 되돌려 수정하고 다시 확인한다.
5. ⑧은 실제 완성 영상의 내용과 맞춰 작성한다. 프로필 링크가 등록되지 않았다면 프로필 안내 문구를 빼 둔다.
6. 사용자에게 검토본을 전달하고, 의견이 오면 ⑨를 실행한다.

독립적인 자료 조사나 서로 다른 영상의 분석은 동시에 할 수 있다. 하나의 영상 파일을 편집·검토하는 등 같은 결과물에 연속으로 손대는 단계는 순서대로 진행한다.

## 인계할 때 공통으로 적을 내용

각 에이전트는 다음 다섯 항목을 짧게 남긴다. 다음 에이전트는 이 기록과 실제 자료를 함께 확인한다.

1. **완료한 일:** 실제로 확인하거나 만든 것
2. **근거:** 원본 링크, 판매 페이지, 영상 파일, 장면 시간 등
3. **결과물:** 파일 경로 또는 본문
4. **미확인 사항:** 접근 실패, 옵션 불명, 사용 권한 미확인 등
5. **다음 단계 주의점:** 대본에서 빼야 할 주장, 편집에서 제외할 컷 등

## 상태 표시

- **완료:** 필요한 자료와 확인을 모두 마친 상태
- **조건부 완료:** 작업은 했지만 특정 근거·권한이 아직 확인되지 않은 상태
- **보류:** 다음 단계에 필요한 핵심 자료가 없어서 진행할 수 없는 상태

조건부 완료를 완료로 바꿔 쓰지 않는다. 예를 들어 브라우저에서 후보를 봤지만 파일을 받지 못했다면 ②는 완료일 수 있어도 ③은 완료가 아니다.

## 작업 방식 고도화

각 역할 파일에는 담당 범위, 입력, 절차, 완료 기준을 둔다. 새로운 실패 사례나 사용자 피드백이 생기면 **해당 역할 파일 하나**와 `변경기록.md`를 수정한다. 바꾸기 전후의 영상 결과나 작업 시간 등 비교할 근거가 있을 때 규칙을 바꾼다.
